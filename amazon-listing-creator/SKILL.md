# 亚马逊 Listing 智能生成器 v3.2

基于亚马逊 **A9 + A10 + COSMO + Alexa + Rufus** 多算法优化的 Listing 生成工具。

## 核心能力

- 支持输入品牌 + 竞品 ASIN 列表，通过 SIF MCP 全自动拆解竞品数据
- 无 MCP 对接时，支持用户上传关键词列表文件
- 生成符合 2026 年 7 月标题新规的 Listing（Item Name ≤75字符 + Item Highlights ≤125字符）
- 自动校验合规黑名单，避免违规词
- 强制联网搜索近 6 个月亚马逊新规进行合规排查
- 以自然流量和链接权重为目标的最终审核优化
- **脚本强制校验**：生成后自动验证格式合规性，不合规直接报错

## 多算法说明

| 算法 | 解决什么问题 | 核心逻辑 | 对应列 |
|------|------------|---------|--------|
| **A9/A10** | 「搜得到」 | 关键词匹配与权重分配 | C列：关键词 |
| **COSMO** | 「搜的人是不是对的人」 | 场景+意图理解，人群标签 | D列：场景词 |
| **Alexa** | 「语音搜得到」 | 口语化场景意图匹配 | D列：场景词 |
| **Rufus** | 「买不买你」 | 事实数据驱动，拒绝空洞描述 | B列：内容文案 |

## 2026 年 7 月标题新规适配

| 字段 | 上限 | 用途 |
|------|------|------|
| **Item Name（商品名称）** | ≤ 75 字符（含空格） | 品牌 + 核心关键词 + 关键属性 |
| **Item Highlights（商品亮点）** | ≤ 125 字符（含空格） | 材质/场景/人群/规格/差异化卖点 |
| **总额度** | 200 字符 | 两个字段均有搜索权重，纳入平台检索索引 |

> ⚠️ 2026年7月27日起，超长标题将由平台 AI 自动重写替换，品牌卖家有14天审核修改权限。

## 输入方式

### 方式一：SIF MCP 自动拆解（推荐）

用户输入：品牌 + 产品名 + 3-5 个竞品 ASIN

Agent 自动调用 SIF MCP 工具：
- `market_get_asin_profile` — 批量查竞品基础信息
- `market_get_asin_keyword_signals` — 查竞品流量词信号
- `market_get_keyword_demand` — 查关键词需求量
- `market_get_asin_aba_footprint` — 查 ABA 搜索词
- `market_discover_competitors` — 竞品发现

### 方式二：用户上传关键词列表

无 SIF MCP 对接时，用户上传关键词列表文件（xlsx/csv/txt），Agent 基于用户提供的数据生成 Listing。

## 关键词埋入主框架

| 优先级 | 来源 | 规则 |
|--------|------|------|
| **P0 必须埋入** | 竞品流量占比 Top 10 | 流量占比 ≥5% → Item Name；1%-5% → BP 开头；<1% → Item Highlights 或 ST |
| **P1 应该埋入** | ABA 周搜索量 Top 30 | 搜索量 ≥10,000/周 → Item Name + BP；1,000-10,000/周 → BP 为主 |
| **P2 可选埋入** | 卖家主动提供的词 | 必须有数据来源才入 |
| **P3 禁止** | AI 凭空补词 | 一律不允许 |

### 品牌词处理规则

竞品流量词中带品牌词开头的（如 `lego advent calendar 2026`）：
1. 去掉品牌词部分，只保留非品牌词根（`advent calendar 2026`）
2. 如果词根已存在于词表 → 去重，不重复入
3. 如果是独立词根 → 正常埋入

## 认证信息规则

- **默认不写** CPC/DV/CE 等认证信息到 Item Name / Item Highlights / BP / ST
- 认证信息走后台属性填写
- **除非用户明确要求写入**，才写入前端文案

## 输出内容

- **Item Name** (商品名称) - A9 优化，≤75字符
- **Item Highlights** (商品亮点) - A9 优化，≤125字符
- **Bullet Points** (五点描述) - Rufus + COSMO 驱动，强制 FBE 结构（Benefit Label → Feature → Benefit → Evidence）
- **Description** (产品描述) - 三段HTML结构（场景需求 → 产品优势 → 价值总结）
- **Search Terms** (后台搜索词) - 无重复、无竞品品牌
- **Validation Summary** (16项自动校验，含真实性质检)
- **主图设计建议** (7条)

## 质量标准

每个输出模块通过三重校验：

- ✅ **A9 合规**: 核心词在 Item Name 出现，五点覆盖长尾词
- ✅ **COSMO 合规**: 明确人群词 + 场景词
- ✅ **Rufus 合规**: 所有卖点有数据/事实支撑，无空洞形容词
- ✅ **合规黑名单**: 未出现违禁词
- ✅ **格式合规**: 脚本 validate_output() 自动校验 6模块 6列结构
- ✅ **中英同步**: 英文内容修改时中文翻译必须同步，标点/句式不一致直接报错
- ✅ **真实性**: 禁止竞品事实移植，所有卖点必须来自用户确认的产品事实
- ✅ **FBE结构**: 每条BP按 Benefit Label → Feature → Benefit → Evidence 逻辑组织
- ✅ **Description**: 三段HTML（场景-功能-价值），使用 Amazon 可用简单 HTML 标签
